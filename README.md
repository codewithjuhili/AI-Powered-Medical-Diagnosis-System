# 🩺 AI-Powered Medical Diagnosis System

An intelligent healthcare application built using **Flask**, **Machine Learning**, and **PostgreSQL** that assists users in identifying potential diseases based on symptoms and provides preliminary health insights.

## 🚀 Features

* Disease Prediction using Machine Learning
* Symptom-Based Diagnosis
* Multiple Disease Detection Models
* User Authentication & Secure Login
* Healthcare Awareness & Educational Content
* Interactive Web Interface
* PostgreSQL Database Integration
* Responsive Design

## ⚡ Installation

### Clone Repository

```bash
git clone https://github.com/codewithjuhili/AI-Powered-Medical-Diagnosis-System.git
cd AI-Powered-Medical-Diagnosis-System
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install flask pandas numpy scikit-learn joblib psycopg2-binary bcrypt
```

### Run Application

```bash
python app_flask.py
```

The application will start on:

```text
http://127.0.0.1:5000
```
